# Rancid Tomatillos - Complete Frontend

## Set Up

Frontend:
- Clone Repo
- `cd` into directory
- `npm i`
- `npm start`
- Navigate to `localhost:3000` in your browser to see the frontend

Backend:
- You shouldn't need to run a backend, as this hits a deployed API endopint. If you'd like to run the BE locally, follow the set up instructions for [this repo](https://github.com/turingschool-examples/rancid-tomatillos-api/)

Branches:
- Note: The `main` branch does not have Router implemented! Move to the `router` branch to see Router in action
